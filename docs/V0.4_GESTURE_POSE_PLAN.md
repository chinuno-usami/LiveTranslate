# v0.4 计划：SteamVR 手势拖动修改字幕距离与角度

> 目标版本：v0.4.x（作为 v0.3 手势 3C 的增强，不阻塞其它功能）
> 状态：计划（未实施）
> 来源：v0.3 已交付「平面内平移抓取」；真机反馈「解锁后只能在一个平面上移动，无法拖动修改距离和角度」
> 前置：`output.steamvr.gesture.enabled = true` 且已解锁（`locked = false`）

---

## 0. 结论摘要

| 能力 | 现状 | 本期目标 | 优先级 |
| --- | --- | --- | --- |
| 平面内平移 | 已有（射线/近场 × 面板平面命中增量） | 保留为 `space = plane` | — |
| 距离（远近 / 深度） | 几乎无效：命中点落在面板平面，法向分量≈0 | **抓取后推拉手柄改距离，且远处也推得动** | P0 |
| 角度（朝向） | 手势从不改旋转；`world` 仅配置写 `world_rotation_deg` 偏航 | **拖动时面板自动朝向用户（默认）；可选手腕扭转微调偏航** | P0（face_user）/ P1（controller_yaw） |
| 持久化 | 松手写回 `distance_m` / 偏移 / `world_position`，**不含** `world_rotation_deg` | 松手一并写回偏航（归一化） | P0 |

**推荐交互（默认 `space = free`）**

- `mode = ray`：**以头显为中心的球坐标映射**。手柄相对头部的方位变化 → 面板方位变化；手柄前推/后拉（离头部更远/更近）→ 面板距离按**比例**放大变化。远处面板也能用一臂行程推远拉近。
- `mode = near`：手已经够得着面板，用 **1:1 位置跟随**（「抓在手里」）。
- 朝向默认 `face_user`：拖到哪里都自动转向用户（只改偏航，保持直立），不需要扭手腕，不会误转。
- 拖动期间两种锚点都用 `set_transform_absolute` 渲染面板，松手再分解回配置字段，避免 hmd 锚点拖动时随转头「游动」。

**明确非目标（本期）**

- 不做无手柄手追 / OpenXR 手骨架。
- 不做 VR 内数值 HUD（距离米数、角度度数实时显示）；桌面设置页仍可精调。
- 不做俯仰 / 滚转手势；首版只改偏航（Y）。
- 不改变现有锁定 / 解锁 / `both_grips` 防误触 / 3A 输入屏蔽语义。
- 不引入第二套 SteamVR Input action；继续 legacy `GetControllerStateWithPose`。

## 1. 现状根因（代码事实）

### 1.1 距离几乎改不动

`compute_hit`（`src/output/steamvr/imp.rs`）无论 `ray` 还是 `near`，最终用于拖动的 `move_hit` 都是**面板平面上的点**：

- `ray`：控制器前向与面板平面求交
- `near`：手柄位置投影到面板平面

`drag_world_delta` 再用「本帧命中 − 上帧命中」。两点共面 ⇒ 增量几乎没有法向分量 ⇒ 推近/拉远无效。

`anchor = "hmd"` 路径里 `apply_hmd_delta` **理论上会改** `distance_m`（`distance_m = start - Δz`），但输入增量本身来自平面命中，正对面板时 `Δz ≈ 0`，所以用户体感仍是「只能平面滑」。

### 1.2 角度完全不能改

- `apply_world_delta` 注释与实现都是「只改位置」。
- `world_matrix_rows` 只读取 `world_rotation_deg[1]`（偏航）；手势路径从不更新该字段。
- `SteamVrPoseUpdate` **没有** `world_rotation_deg`；`persist_steamvr_pose_update` 也不写旋转。
- `anchor = "hmd"` 下 `hmd_local_matrix` 旋转部分为单位阵：面板朝向 = 头显朝向。`horizontal_offset_m` 较大时面板不正对眼睛（斜视）。

### 1.3 拖动循环的其它现状约束

- VR 线程主循环 `FRAME_INTERVAL = 33ms`（约 30Hz），拖动期间每帧 `apply_transform`。
- hmd 锚点通过 `set_transform_tracked_device_relative` 提交：偏移按 30Hz 计算、由合成器按头显姿态实时套用。
- `force_cancel`（Dashboard / `tracking_ok = false` / 面板隐藏 / HMD 无效）与 `DragCancelled` 都会 `live_config = shared_config.clone()` 丢弃 live 值。
- 单帧位移上限 `MAX_FRAME_DELTA_M = 0.25`，用于**增量**截断。

### 1.4 相关落点

| 位置 | 现状 |
| --- | --- |
| `src/output/steamvr/imp.rs` `compute_hit` / 拖动循环 | 平面命中增量驱动位置 |
| `src/output/steamvr/gesture.rs` `drag_world_delta` / `apply_*` | 无旋转 API；HMD 深度仅理论可用 |
| `src/output/steamvr/mod.rs` `SteamVrPoseUpdate` / `hmd_local_matrix` | 仅 distance + 偏移 + world_position；hmd 旋转为单位阵 |
| `src/main.rs` `persist_steamvr_pose_update` | 不持久化旋转 |
| `src/config/mod.rs` `GestureConfig` / validate | 无 `space` / `orientation`；`world_rotation_deg` 每轴 `[-360, 360]` |
| `src/config/schema.rs` | 设置页字段由 schema 生成 |
| `config/default.toml` | 默认值与注释 |
| `src/output/steamvr/imp.rs` `world_matrix_rows` | 仅 yaw |

## 2. 目标与成功标准

### 2.1 用户可见目标

1. 解锁并抓取后，**前后推拉手柄能明显改变字幕远近**，面板在 3m 外也不需要走动。
2. 拖动到任意方位，面板**自动正对用户且保持直立**（默认）。
3. 可选：扭转手柄微调偏航（`orientation = controller_yaw`）。
4. 默认仍不易误触：保留 `plane` 模式；朝向默认不受手腕扭转影响。
5. 松手后距离 / 偏移 / 偏航写回配置，重启应用仍在。
6. Dashboard 打开、tracking 丢失、锁定、epoch 变化时的取消语义与 v0.3 一致，且面板恢复到拖动前的位置与变换模式。

### 2.2 验收标准（真机 + 单测）

| # | 场景 | 期望 |
| --- | --- | --- |
| A1 | free + ray，hmd 锚点，面板 1.5m，手柄沿视线前推 0.3m | `distance_m` 增大 ≥ 0.8m；后拉同幅度回到约 1.5m（±0.1m） |
| A2 | free + ray，面板 3m，前推 0.3m | 距离增大 ≥ 1.5m（比例映射生效）；clamp 在 `[0.2, 10]` |
| A3 | free + ray，world 锚点，左右/上下挥动手柄 | 面板沿以头为中心的球面移动；`world_position` 每轴 clamp `[-100, 100]` |
| A4 | free，拖动中转头 / 身体不动 | 面板**在世界中保持静止**（hmd 锚点也一样），无 30Hz 顿挫感 |
| A5 | free + near | 面板 1:1 跟随手柄位置 |
| A6 | `space = plane` | 行为与 v0.3 一致 |
| A7 | `orientation = face_user`，world，把面板绕身体拖开 90° | 面板仍正对用户；松手后 `world_rotation_deg[1]` 持久化且在 `(-180, 180]` |
| A8 | `orientation = keep` | 偏航不变（v0.3 行为） |
| A9 | `orientation = controller_yaw` | 手柄绕竖直轴扭转 Δ，面板偏航在 face_user 基础上叠加 Δ；手柄俯仰/滚转不影响 |
| A10 | hmd 锚点松手 | 面板停在松手瞬间的世界位置后转为头显跟随，无可见跳变（clamp 触边界除外） |
| A11 | 取消（Dashboard/断追/锁定/epoch） | 丢弃 live 值，面板回到拖动前位置；hmd 锚点恢复 tracked-device-relative 变换 |
| A12 | tracking 毛刺（单帧手柄跳变 > 阈值） | 本帧丢弃并重建吸附，面板不瞬移、不追赶飞行 |
| A13 | 单测 | 球坐标映射、深度比例、face_user yaw、yaw 与 `world_matrix_rows` 互逆、yaw 归一化、hmd 反推、clamp、pose 持久化字段 |

## 3. 交互设计

### 3.1 拖动空间：`gesture.space`

```toml
[output.steamvr.gesture]
# plane = v0.3 行为（射线/近场平面命中增量）
# free  = 可推拉距离（ray：以头为中心的比例映射；near：1:1 跟随）
space = "free"
```

| 值 | 位移来源 | 距离 | 适用 |
| --- | --- | --- | --- |
| `plane` | 面板平面命中点差分（现状） | 基本不变 | 只要左右上下微调、怕前后误触 |
| `free`（**默认**） | 见 §3.2 / §3.3 | 可推拉 | 需要摆远近 |

`mode = ray | near` 仍只决定**如何进入抓取**（命中测试，`both_grips` 必须 pointer 命中）；在 `free` 下同时决定拖动映射：

| | `mode = ray` | `mode = near` |
| --- | --- | --- |
| `space = plane` | v0.3 射线平面增量 | v0.3 近场投影增量 |
| `space = free` | 头中心球坐标映射（§3.2） | 1:1 位置跟随（§3.3） |

### 3.2 Free + ray：以头显为中心的球坐标映射（推荐默认）

为什么不用刚体吸附（`P = C · inv(C0) · P0`）：手臂前后行程约 0.5m，而 `distance_m` 范围 `[0.2, 10]`；面板在 3m 时 1:1 推拉几乎没用。另外手腕旋转 10° 会让 3m 外面板横移约 0.5m，抖动被杠杆放大。

**抓取瞬间（`DragStarted` 当帧，而非 arming 开始时，避免 250ms arming 期间手已移动造成跳变）记录：**

```text
pivot  = HMD 位置（Standing，冻结；只取平移，转头不影响映射）
v0     = C0.pos - pivot          r0 = max(|v0|, R_MIN)     # R_MIN = 0.15m，手贴脸时防退化
u0     = P0.pos - pivot          d0 = |u0|
(az_c0, el_c0) = 方位角/仰角(v0)
(az_p0, el_p0) = 方位角/仰角(u0)
```

**每帧：**

```text
v  = C.pos - pivot,  r = max(|v|, R_MIN)
Δaz = wrap_pi(az(v) - az_c0)
Δel = el(v) - el_c0
az_p = az_p0 + Δaz
el_p = clamp(el_p0 + Δel, -EL_MAX, EL_MAX)          # EL_MAX = 75°，远离极点奇异
d    = clamp(d0 · exp(G · (r - r0)), 0.2, 10)        # G = DEPTH_GAIN · sensitivity
p    = pivot + d · dir(az_p, el_p)
```

- 角度 1:1：面板沿以头为中心的球面跟手，手感接近射线拖动但不受手腕扭转杠杆影响（只用手柄**位置**）。
- 深度按比例：`DEPTH_GAIN ≈ 3 /m` 时前推 0.3m ≈ ×2.5，后拉 0.3m ≈ ×0.4；远近手感一致、永不为负。
- `sensitivity`（现有字段，范围 `[0.2, 3]`）在 free 下作为深度增益倍率；文案同步说明。
- 常量 `R_MIN` / `EL_MAX` / `DEPTH_GAIN` 放 `gesture.rs`，D3 真机调参。

### 3.3 Free + near：1:1 位置跟随

```text
# 抓取时
t_attach = P0.pos - C0.pos       # 世界系位置偏移，不随手腕转动
# 每帧
p = C.pos + t_attach
```

只用位置、不用控制器旋转，避免手腕扭动带动面板。

### 3.4 朝向：`gesture.orientation`

```toml
[output.steamvr.gesture]
# face_user      = 拖动时偏航自动朝向用户（默认）
# keep           = 保持原偏航（v0.3 行为）
# controller_yaw = face_user 基础上叠加手柄绕竖直轴的扭转
orientation = "face_user"
```

只作用于 `space = free`；`plane` 保持 v0.3 不改朝向。俯仰、滚转始终不改（字幕保持直立）。

**偏航计算**（面板可视面朝 +Z，`world_matrix_rows` 的 Z 列为 `(sin yaw, 0, cos yaw)`）：

```text
f = 水平化(pivot - p)                       # 面板指向用户
yaw_face = atan2(f.x, f.z)

face_user:       yaw = yaw_face
keep:            yaw = yaw_at_grab
controller_yaw:  yaw = yaw_face + wrap_pi(yaw_ctrl(C) - yaw_ctrl(C0))
                 # yaw_ctrl = 手柄前向在水平面投影的方位角；投影长度 < 0.2 时（手柄近乎竖直）沿用上一帧偏移
```

不从 `C · A` 的完整旋转里分解欧拉角（大俯仰时数值不稳）。

**按锚点**

| 锚点 | 拖动期渲染朝向 | 写回 |
| --- | --- | --- |
| `world` | `R_y(yaw)`，直立 | `world_rotation_deg[1] = normalize(yaw)`；`[0]`/`[2]` 原样保留 |
| `hmd` | **当前 HMD 旋转**（与松手后头显跟随一致，松手无朝向跳变）；`orientation` 首版对 hmd 不生效 | 不写 `world_rotation_deg` |

hmd 锚点下「面向用户」需要改 `hmd_local_matrix`（由 `horizontal_offset_m` / `height_offset_m` 推出朝向，`yaw = atan2(-x, d)`），属渲染时行为变化，会打破现有 `horizontal_offset_default_zero_matches_v02` 等等价性假设，放到 D2 作为显式开关（§9 Q3），不新增 `hmd_rotation_deg` 字段。

### 3.5 可选增强（本期不做）

- 双手拉伸改 `width_m` / 字号。
- 摇杆微调距离（不抓取时）。
- 俯仰手势 / `yaw_pitch`。
- 拖动中桌面浮窗显示 live 距离/角度读数。

## 4. 渲染、写回与数值

### 4.1 拖动期间统一用绝对变换

现状 hmd 锚点按 30Hz 算偏移再用 tracked-device-relative 提交：转头时合成器实时套用头显姿态，但偏移每 33ms 才追上，面板会随转头游动/顿挫。改为：

```text
Dragging && space == free:
  P_world = TR(R_drag, p)          # p 来自 §3.2/§3.3；R_drag 见 §3.4
  overlay.set_transform_absolute(Standing, P_world)
松手:
  分解 P_world → live_config（§4.2），apply_transform(live_config) 恢复原锚点模式
取消:
  live_config = shared_config.clone()；**必须**立即 apply_transform(live_config)
  （现状取消后只有 dragging/retry_due 才 apply；hmd 锚点会残留 absolute 变换）
```

可选：Dragging 期间把位姿更新节奏提到 ~11ms（纹理渲染节奏不变），D1 先测量再决定。

### 4.2 从面板位姿分解到配置

**World 锚点**

```text
world_position        = clamp_world_position(p)
world_rotation_deg[1] = normalize_deg(yaw)     # (-180, 180]，orientation != keep 时更新
```

新增 `compose_world_rows(pos, yaw)` 供 `world_matrix_rows` 与手势共用，单测保证 `extract_yaw(compose(yaw)) == yaw`（`atan2(r02, r00)`）。

**HMD 锚点**（松手时用**当前** HMD 姿态反推，面板停在原地再转为头显跟随）：

```text
L = inv_rigid(H_current) · p
horizontal_offset_m = L.x
height_offset_m     = L.y
distance_m          = -L.z
```

已知限制：拖动中若转头较大（如 90°），反推的 `horizontal_offset_m` 可能超出 `[-2, 2]` 被 clamp，松手会跳一下。D1 接受并在文档说明；D3 视情况在触边界时 haptic 提示。

### 4.3 Clamp、毛刺与偏航归一化

| 字段 | 区间 |
| --- | --- |
| `distance_m` | `[0.2, 10]`（free+ray 在映射中即 clamp `d`） |
| `horizontal_offset_m` / `height_offset_m` | `[-2, 2]` |
| `world_position[*]` | `[-100, 100]` |
| `world_rotation_deg[1]` | 写回前归一化到 `(-180, 180]`（validate 为 `[-360, 360]`，不归一化多转几圈会校验失败） |

**毛刺处理改为「丢帧 + 重建吸附」而非限速追赶**：free 模式是绝对目标映射，沿用 `limit_frame_delta` 会让毛刺后面板花多帧飞过去。

```text
if |C.pos - C_prev.pos| > JUMP_M (≈0.3m/帧):
    跳过本帧；下一有效帧以「当前面板位姿 + 当前手柄」重新记录 §3.2/§3.3 的抓取基准
```

`plane` 模式保留 `MAX_FRAME_DELTA_M` 截断不变。tracking 失效仍走现有 `force_cancel`。

### 4.4 持久化结构变更（D1 一并完成）

```rust
// src/output/steamvr/mod.rs
pub struct SteamVrPoseUpdate {
    pub distance_m: f32,
    pub height_offset_m: f32,
    pub horizontal_offset_m: f32,
    pub world_position: [f32; 3],

}
```

- `pose_update_from_config` 带上 `world_rotation_deg`。
- `persist_steamvr_pose_update`：对 `[1]` 归一化后写入，并加入 `output.steamvr.world_rotation_deg` 的变更项。
- stub / `status_exposes_gesture_fields...` 测试同步。

### 4.5 兼容性注意

- `world_rotation_deg[0]` / `[2]` 现状被忽略，用户配置里可能残留非零值。本期继续忽略且原样保留；若后续启用俯仰，必须先迁移归零并写入 UPGRADING。

## 5. 配置设计

```toml
[output.steamvr.gesture]
enabled = false
locked = true
# ... 现有字段不变 ...

# 拖动空间：plane | free（free：射线=以头为中心推拉，近距离=1:1 跟随）
space = "free"
# 拖动时朝向：face_user | keep | controller_yaw（仅 free；首版仅 world 锚点生效）
orientation = "face_user"
# 位移灵敏度（plane：平面位移倍率；free：推拉深度增益倍率）
sensitivity = 1.0
```

校验（`GestureConfig` / `validate`）：

- `space ∈ {plane, free}`；`orientation ∈ {face_user, keep, controller_yaw}`
- 旧配置缺字段走 serde default（`free` / `face_user`）

设置页（`src/config/schema.rs` 注册，`settings.js` 由 schema 渲染，一般无需改）：

- 「拖动空间」「拖动时朝向」两个 select，放 gesture 分组。
- 文案：`plane` = 仅平面；`free` = 可推拉距离；推荐「近距离 + free」手抓摆放、「射线 + free」远距离摆放。
- `sensitivity` 帮助文案补 free 下含义。

`config/default.toml` 同步字段与注释；README / QUICKSTART / UPGRADING 补充距离/角度说明与排错（「只能平面动 → 检查 `space`」）。

## 6. 状态机与线程改动

### 6.1 拖动会话数据

`GestureState` 的相位与 `GestureTransition` 不变；新增 free 会话（`DragStarted` 当帧由 `imp.rs` 用当帧 HMD/手柄/面板位姿初始化）：

```rust
enum FreeDrag {
    Sphere {               // free + ray
        pivot: [f32; 3],
        r0: f32,
        az_c0: f32, el_c0: f32,
        d0: f32,
        az_p0: f32, el_p0: f32,
        yaw_ctrl0: f32,
        yaw_at_grab: f32,
    },
    Follow {               // free + near
        pivot: [f32; 3],   // face_user 仍需头部位置
        t_attach: [f32; 3],
        yaw_ctrl0: f32,
        yaw_at_grab: f32,
    },
}

struct FreeDragSession {
    mode: FreeDrag,
    prev_controller: [f32; 3],  // 毛刺检测
    needs_rebase: bool,
    panel: Mat3x4,              // 当前面板世界位姿（渲染 + 松手分解 + rebase）
}
```

映射计算为纯函数（输入会话 + 当帧手柄/HMD，输出面板位姿），放 `gesture.rs` 便于单测；`imp.rs` 只负责采样与提交。

### 6.2 VR 线程主循环（伪代码）

```text
DragStarted:
  若 space == free：用当帧 HMD/右手/panel_world_matrix 初始化 FreeDragSession
Dragging && space == free:
  若手柄跳变 → needs_rebase，跳过
  若 needs_rebase → 以 session.panel + 当前手柄重建基准
  session.panel = map(session, C, H)
  set_transform_absolute(session.panel)
Dragging && space == plane:
  沿用 v0.3 drag_world_delta 路径
DragReleased:
  free：session.panel 按 anchor 分解到 live_config（§4.2）
  apply_transform(live_config)；pending_pose = pose_update_from_config(live_config)
DragCancelled / force_cancel:
  丢弃 session；live_config = shared_config.clone()；立即 apply_transform
```

门禁不变：`locked` / Dashboard / tracking_ok / `panel_visible` / `config_epoch`。

**Pointer**：free 拖动时 `plane_hit` 来自的面板已在移动，光标语义变化。D1 拖动期间把光标固定在「抓取点在面板局部坐标 × 当前面板位姿」；或简单隐藏（D3 定稿）。

### 6.3 矩阵/几何工具（`gesture.rs`，纯函数 + 单测）

- `mat3x4_inverse_rigid`（`R^T`, `-R^T t`）
- `dir_from_az_el` / `az_el_of`、`wrap_pi`、`normalize_deg`
- `face_user_yaw(pivot, p)`、`controller_yaw(C)`
- `compose_world_rows(pos, yaw)` / `extract_yaw`（与 `world_matrix_rows` 共用）
- `map_sphere` / `map_follow`、`hmd_offsets_from_world(H, p)`

## 8. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 比例深度映射过灵敏 | 字幕一下推很远 | `sensitivity` 可调；clamp；D3 调 `DEPTH_GAIN`；保留 `plane` |
| 手贴近头部时 `r` 退化 | 方位角跳变 | `R_MIN` 下限；`r < R_MIN` 时方位沿用上一帧 |
| 仰角接近 ±90° | 方位奇异 | `EL_MAX = 75°` clamp |
| 拖动期 absolute / 平时 relative 切换遗漏 | hmd 锚点取消后面板钉在世界 | 取消/松手统一立即 `apply_transform`；A11 回归 |
| hmd 松手 clamp 跳变 | 体验小瑕疵 | 文档说明；D3 触边界 haptic |
| tracking 毛刺 | 瞬移 / 追赶飞行 | 丢帧 + rebase（§4.3） |
| controller_yaw 手柄竖直时方位不稳 | 偏航抖动 | 水平投影过短时冻结偏移 |
| 偏航累计超出 validate | 写回失败 | 写回前归一化 `(-180, 180]` |
| 残留 `world_rotation_deg[0/2]` | 未来启用俯仰时面板突然倾斜 | 本期原样保留且不应用；启用前迁移 |
| 30Hz 拖动顿挫 | 体感差 | 绝对变换已消除转头游动；必要时 Dragging 提频 |
| 与 3A 屏蔽同时开启 | 拖动中断 | 维持现有 UpdateActionState 路径；D3 真机回归 |
| 曲面 `curvature` 大时命中与视觉不一致 | 难抓 | arming 仍用切平面；文档说明 |
